# Bhuvix Technology Website

Official website for **Bhuvix Technology** — Empowering tech careers with premium CV revamping, targeted job applications, and career transition services.

## Overview
- **Tech Stack**: HTML5, Vanilla CSS3, Modern JavaScript
- **Pages**:
  - `index.html` - Homepage with service overviews, pricing tiers, and client testimonials
  - `services.html` - Full service breakdown & packages
  - `plans.html` - Pricing plans and details
  - `how-it-works.html` - 4-step workflow process
  - `career-advice.html` - Guides, tips, and career strategies
  - `employers.html` - Hiring solutions for organizations
  - `tools.html` - Career tools and resources
  - `blog.html` - Articles and industry insights
  - `contact.html` - Contact and inquiry form
  - `privacy-policy.html` & `terms-conditions.html` - Legal and policy pages

## Deployment
This static website is configured to deploy directly to **GitHub Pages** from the root directory (`/`) on the `main` branch.
